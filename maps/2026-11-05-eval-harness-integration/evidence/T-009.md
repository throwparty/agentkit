# T-009 — Adapter packaging and versioning

**Answer: package Tackle with the existing goreleaser matrix and ship a
`tackle-acp` launcher in the same archive; publish an ACP registry entry that
points at it. No Tackle product change is required.**

## Evidence

### Existing release matrix

`.goreleaser.yaml:23-29` already builds Tackle:

```yaml
- id: tackle
  binary: agentkit-tackle
  builder: rust
  flags:
    - --release
    - --package=agentkit-tackle
  targets: *default_targets
```

`default_targets` (`.goreleaser.yaml:10-15`) covers
`x86_64-unknown-linux-gnu`, `x86_64-apple-darwin`, `x86_64-pc-windows-gnu`,
`aarch64-unknown-linux-gnu`, `aarch64-apple-darwin`. Archives are `.tar.gz` /
`.zip`, signed with cosign, with SBOMs.

There is no `aarch64-unknown-linux-musl` target, which is the safest choice for
task containers with older glibc. Add it if a container smoke test shows a glibc
mismatch.

### ACP registry schema

`agentclientprotocol/registry/agent.schema.json` requires `id`, `name`,
`version`, `description`, and `distribution`. A binary target is:

```json
"binary": {
  "linux-x86_64": {
    "archive": "https://.../tackle.tar.gz",
    "sha256": "<64 hex chars>",
    "cmd": "tackle-acp",
    "args": [],
    "env": {}
  }
}
```

The installer extracts the archive and runs `cmd`. A launcher script shipped
alongside the binary is therefore a valid entry point.

### What the launcher must carry

From T-003: write user config, stage prompts, isolate `--config-dir` /
`--db-path`, `exec tackle stdio`. The launcher is a shell script or a small Rust
bin; a shell script is enough and keeps the registry archive simple.

## Assessment

- **Proven:** targets, archive format, registry schema.
- **Inferred:** a launcher script in the archive is accepted by registry
  installers.
- **Unverified:** glibc compatibility in Harbor/BenchFlow task images; whether
  the generic ACP agent passes `skills_dir` to the launcher or whether the
  launcher must read a fixed path (`/runtime/skills` or
  `environment.skills_dir`).

## Open choices

- `agentkit-tackle` vs `tackle` as the shipped binary name; the launcher can
  `exec` either.
- Whether to add `aarch64-unknown-linux-musl` now or after a container smoke
  test.
