# T-014 — Do the runner's SWE-bench tasks preserve official scoring?

**Answer: likely yes for the test patch, unproven for the pass rule. Treat
Harbor's SWE-bench tasks as a candidate until a 5-instance overlap with the
official harness agrees on resolved/unresolved.**

## Evidence

### Harbor has SWE-bench tasks

- Harbor Hub: `swe-bench/swe-bench-verified` and
  `scale-ai/swe-bench-pro`.
- Harbor source: `adapters/swebenchpro/README.md` converts SWE-bench Pro
  instances into Harbor-compatible tasks.
- Hugging Face `DCAgent/swebench-verified`: "SWE-bench Verified (500 tasks) via
  Harbor adapter"; the commit message says "SWE-bench test patch". This is
  evidence the task carries the test patch, not that the pass rule matches.

### The official rule

`https://www.swebench.com/SWE-bench/reference/harness/` and the evaluation guide:
the harness applies the model patch, applies the test patch, runs the
repository tests, and decides resolved/unresolved. The instance metadata carries
`FAIL_TO_PASS` and `PASS_TO_PASS`; the evaluation is not a generic "tests pass"
check.

A Harbor task's verifier is `tests/test.sh`, which writes
`/logs/verifier/reward.txt`. Whether that script implements the same
FAIL_TO_PASS/PASS_TO_PASS comparison is the open question.

## Probe design

1. Pick 5 SWE-bench Verified instances with gold patches.
2. Run the official harness with `--predictions_path gold` and record
   resolved/unresolved.
3. Run the same 5 instances as Harbor tasks with a gold patch or the same agent
   patch; record rewards.
4. Compare per instance. Any disagreement is a fidelity bug or a documented
   difference (e.g., test selection, environment image, timeout).
5. Only then trust Harbor's aggregate for "confidence in Tackle".

## Assessment

- **Proven:** Harbor has SWE-bench datasets/tasks and carries test patches.
- **Inferred:** the verifier is intended to reproduce the official rule.
- **Unverified:** per-instance agreement; whether Harbor's images and test
  selection match the official harness.

## Consequence

If the 5-instance overlap disagrees, the official harness remains the scoring
authority and Harbor is the rollout runner: export predictions from Harbor and
score with `swebench.harness.run_evaluation`. That is a second tool for scoring,
but it is the benchmark's own harness, not a competing eval framework.
