# T-019 — where a rewritten branch is reconciled

**Question:** When a user rewrites a sandbox's branch, where is the difference resolved?

**Answer:** The sandbox never merges. It adopts the rewrite when its workspace matches its own branch and holds the shared branch at the user tip when it does not. The host resolves the difference in a linked worktree on a temporary branch under the data directory. The merge uses the recorded synced revision as its base.

## Why the host

The merge is between the user's intent and the agent's work. The user has the editor, the tests and the history. The sandbox has files and a shell. A three-way merge with markers in the sandbox asks an agent to arbitrate a rewrite it cannot see in full.

## The state

`Base` is `Synced` or `HistoryMoved` or `ContentMoved`. `Workspace` is `Clean` or `Dirty`. `Merge` is `None` or `Pending` or `Conflicted`. Four trees decide: the synced revision, the branch tip, the sandbox branch tip, and the workspace. `Workspace` compares the workspace with the sandbox branch, so a branch the user already reconciled reads Clean. `Pending` records a held divergence. Git never writes `Conflicted`.

## The Git refs

`refs/heads/litterbox/<name>` is the shared branch. `refs/litterbox/workspaces/<name>` is the sandbox branch and the `ours` side. `refs/litterbox/synced/<name>` is the merge base. The refs live in the repository that holds the branch.

## The base

A rebase replaces the commits the sandbox branch descends from. Git's inferred merge base then lies below `synced`, and a plain `git merge` reports the user's history movement as content changes. `git merge-tree --write-tree --merge-base=<synced>` asks the right question.

## The workflow

`status` reports the divergence and the conflicting paths. `reconcile` creates the linked worktree and stops with markers and index stages and `MERGE_HEAD` in place. The user resolves and commits. `reconcile --finish` fast-forwards the branch when it is free and prints `git merge --ff-only` when the user's checkout holds it. `reconcile --abort` removes the worktree. No command writes the user's checkout.
