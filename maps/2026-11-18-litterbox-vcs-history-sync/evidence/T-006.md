# T-006 — `rmcp` structured `workspace` block

**Question:** Can `rmcp` tool results carry a structured `workspace` block alongside the existing content, and what is the exact schema?

**Answer:** Yes. Pinned `rmcp` is **3.9.0** (`Cargo.lock:3727`). `CallToolResult` carries `content: Vec<ContentBlock>` plus an optional `structured_content: Option<Value>` serialised as `structuredContent` (`src/model.rs:4139-4166`). `CallToolResult::success(Vec<ContentBlock>)` accepts any number of blocks (`src/model.rs:4241`), and `ContentBlock::json` turns any `Serialize` value into a JSON text block (`src/model/content.rs:268`). The tool can therefore keep its existing output block and append a second `ContentBlock::json(workspace)`; alternatively `CallToolResult::structured(value)` sets both the text content and `structuredContent` (`src/model.rs:4326`).
