# T-022 — how each VCS reports a conflicted tip

**Question:** How does each VCS report a conflicted tip (jj commit state, Git marker tree), and what does the MCP `workspace` block say?

**Answer:** Add a `Vcs` operation that answers "is this revision conflicted?".

- **jj:** native. `jj resolve --list -r <revision>` lists the conflicted paths, and the commit template exposes a boolean: `jj log --no-graph -r <revision> -T 'if(conflict, "conflicted", "clean")'`. The bridge bookmark can point at a conflicted commit.
- **Git:** Git has no conflicted commit. The normal path is resolve-before-push, with the host staging worktree for divergence. As a safety net, scan the tip tree's tracked files for conflict markers: `git grep -n -E '^(<<<<<<<|=======|>>>>>>>)' <revision> -- .`. A marker tree is held; a clean tree is adoptable.
- The check belongs to the VCS backend; the orchestrator asks the question and never parses a VCS-specific state itself.

The model-facing result is a `held` state, not a conflict the agent resolves:

```json
{
  "state": "held",
  "reason": "bridge tip is conflicted",
  "synced": "…",
  "bridge_tip": "…",
  "conflicts": ["src/a.rs"],
  "next": "resolve the bridge conflict and push; the sandbox is on the last good revision"
}
```

The agent continues on the main workspace. `sandbox-reconcile` is not the resolution path here; the user resolves on their side. Agent-side resolution is T-023.

## Evidence

The jj probe in [`T-021/output.txt`](T-021/output.txt) shows `conflicted` / `file.txt    2-sided conflict` on the bridge bookmark and `clean` / `No conflicts found` on the sandbox bookmark. The Git probe shows the marker scan holding and then adopting after resolution.

## Primary Git vs safety net

The primary Git path for a divergence remains the host staging worktree in `adrs/2026-11-22-adopt-rewritten-branches`: the user resolves before the branch moves, so the bridge never carries a marker tree. The scan is for a tree a user committed without resolving; it holds the same way jj holds a conflicted commit.
