# T-036: do namespace inodes stay stable while the sandbox lives?

**Question.** Can a later process identify the sandbox by the namespace inodes
that bwrap reported at create, or do they change while the sandbox runs?

**Method.** Wait until the view is built. Read
`/proc/<sandbox-pid>/ns/{user,ipc,net,pid,mnt,uts,cgroup}`. Join three commands.
Read the same seven inodes again. Reproduce with
`evidence/T-033-039-probes.sh`.

**Observation.**

```
user:[4026534465] ipc:[4026534408] net:[4026534411]
pid:[4026534409] mnt:[4026534406] uts:[4026534407]
cgroup:[4026534410]
inodes unchanged after 3 commands: yes
```

**Conclusion.** Yes. The seven inodes are identical after three joins, so a
record that carries them can be checked before every join. An inode is reused by
the kernel after a namespace dies, so the check must be paired with the process
start time, which the same probe supports because the sandbox pid was stable
throughout.
