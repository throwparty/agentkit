# T-010: per-sandbox resource limits

**Question.** Can per-sandbox resource limits be applied without a long-lived supervisor?

**Method.** `adrs/2026-10-31-linux-bwrap-lifecycle/poc/limits.sh` on NixOS with a systemd user manager.

**Observation.** The harness ran under a transient user scope with `MemoryMax=64M`, `MemorySwapMax=0` and `TasksMax=16`. A 256 MiB allocation failed and a 64-thread creation failed; the host stayed responsive. Both failures surfaced as a failed scope. The process-group fallback has no limits.

**Conclusion.** Yes on systemd hosts, through transient scope properties. The fallback runs unlimited.
