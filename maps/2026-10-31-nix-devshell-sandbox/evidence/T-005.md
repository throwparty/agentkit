# T-005: egress filtering with bwrap

**Question.** Can bubblewrap allow one destination and deny another?

**Method.** The bwrap README's network namespace section and the man page's namespace options.

**Observation.** `containers/bubblewrap` README:

> Network namespaces (CLONE_NEWNET): The sandbox will not see the network. Instead it will have its own network namespace with only a loopback device.

The mechanism provides no per-host, per-address or per-port rule. `--unshare-net` gives an isolated namespace; `--share-net` gives the host network in full.

**Conclusion.** bwrap cannot express an egress allowlist. Options are an unshared namespace, the full host network, or an unshared namespace with a proxy on a socket the sandbox can reach. Destination filtering lives in the proxy.
