# T-037: cgroup v2 and a usable user scope on this host

**Question.** Does this host offer cgroup v2 with a user manager that can start
a transient scope, which is what pause, resume and limits need?

**Method.** Read the cgroup file system type, ask the user manager for its
environment, and start a scope.

```
stat -fc %T /sys/fs/cgroup
systemctl --user show-environment
systemd-run --user --scope --unit=bwrap-probe-<pid> --quiet true
```

Reproduce with `evidence/T-033-039-probes.sh`.

**Observation.**

```
cgroup fs: cgroup2fs
user manager: present
user scope: starts
```

**Conclusion.** Yes on this host. The scoped mode is the default here, and the
degraded mode is for hosts that answer no. T-009 and T-010 already measured what
the scope provides once it starts.
