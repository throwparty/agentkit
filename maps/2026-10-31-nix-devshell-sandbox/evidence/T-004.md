# T-004: sharing the Nix store

**Question.** Can each sandbox use the host Nix store directly?

**Method.** Store-path semantics from the Nix manual; mount semantics from the bwrap man page.

**Observation.** The Nix manual defines a store path as a digest plus a symbolic name, and states that "a store path will always reference exactly one store object". Referential integrity holds when paths are read within the same store directory.

bwrap `--ro-bind SRC DEST` bind-mounts a host path read-only. The man page notes that bind mounts are `nodev` by default and can be made read-only.

**Conclusion.** A read-only bind of `/nix/store` gives every sandbox the same closure at zero copy cost. Writes go through an explicit channel: the host daemon or a private store.
