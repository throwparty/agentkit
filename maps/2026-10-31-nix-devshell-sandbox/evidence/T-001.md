# T-001: the App Sandbox entitlement API and unsigned binaries

**Question.** Can the App Sandbox entitlement API confine an unsigned devShell binary?

**Method.** Apple's App Sandbox documentation and the Darwin spike's signature and apply results.

**Observation.** App Sandbox has two entry points: the entitlement API (`com.apple.security.app-sandbox`, applied from the code signature) and `sandbox_init`, which installs an arbitrary profile. The Darwin helper was adhoc-signed with no TeamIdentifier (`adrs/2026-10-31-darwin-app-sandbox/poc/results/t-005-apply.md`) and confined through `sandbox_init`.

**Conclusion.** The entitlement API requires a signed application bundle, so an unsigned devShell binary uses the deprecated `sandbox_init` entry point into App Sandbox.
