# T-001: the App Sandbox entitlement API and unsigned binaries

**Question.** Can the App Sandbox entitlement API confine an unsigned devShell binary?

**Method.** Apple's App Sandbox documentation and the Darwin spike's signature and apply results.

**Observation.** macOS exposes two policy sources for the sandbox. The App Sandbox entitlement API enables `com.apple.security.app-sandbox`; the system derives the policy from the signed bundle. `sandbox_init` installs an arbitrary Seatbelt/SBPL profile and does not apply the App Sandbox entitlement policy. The Darwin helper was adhoc-signed with no TeamIdentifier (`adrs/2026-10-31-darwin-app-sandbox/poc/results/t-005-apply.md`) and confined through `sandbox_init`.

**Conclusion.** The App Sandbox entitlement API requires a signed application bundle, so an unsigned devShell binary cannot use it. The spike exercised the `sandbox_init` entry point with a Seatbelt profile; it did not demonstrate App Sandbox entitlement support.
