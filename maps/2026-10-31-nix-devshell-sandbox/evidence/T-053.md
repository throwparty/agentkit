# T-053. Can a project supply Xcode itself as contributed read paths?

Answer: yes. A compiler builds with the Xcode installation root and the licence
plist granted as read mounts, and needs no writable host path. The backend can
drop all knowledge of Xcode.

Host: macOS 27.2.1 (26B131), arm64. Probed 2026-11-14.

## Reproduce

```
helper --workspace <ws> --without-developer \
  --read /Applications/Xcode.app \
  --read /Library/Preferences/com.apple.dt.Xcode.plist \
  -- /usr/bin/clang -o <ws>/hello <ws>/hello.c
```

`T-043-helper.c` is the T-043 probe, built as `build/helper`: deny default, a platform baseline that excludes
every developer path, and `--read` for each contributed path. The environment is
`env -i` with `PATH=/usr/bin:/bin`, `HOME=<ws>` and `TMPDIR=<ws>`. No writable
path is granted beyond the workspace.

Workload:

```c
#include <stdio.h>
int main(void){printf("built\n");return 0;}
```

## Observation

```
clang: error: couldn't create cache file '/var/folders/.../T/xcrun_db-wqEdR9jS' (errno=Operation not permitted)
2026-11-14 13:10:45.196 xcodebuild[6707:716852]  DVTFilePathFSEvents: Failed to start fs event stream.
clang: error: couldn't create cache file '/var/folders/.../T/xcrun_db-cM2MYkKV' (errno=Operation not permitted)
exit=0
-rwxr-xr-x  ...  <ws>/hello-e
built
```

The cache warnings are non-fatal. The build succeeds and the binary runs.

## Comparison

T-046 established that the developer directory alone is insufficient: clang
reaches siblings of `Contents/Developer`, and it reads the licence plist. Both
are ordinary absolute paths, so both can be contributed as read mounts. The
backend does not need to discover them, widen anything, or grant a writable
host path.

## Consequence

The backend has no toolchain awareness: no `xcode-select`, no installation
root, no licence plist, no `toolchain` key. A project that needs a compiler
names the read paths. The mount validation already accepts them, and the
credential denies do not cover `/Applications` or `/Library/Preferences`.

## Caveats

- The cache warnings mean a compiler writes to a host path it cannot reach. A
  toolchain that treats the failure as fatal would need a writable grant the
  contract does not have; none was found here.
- The licence plist is host policy. A fresh machine may refuse until the licence
  is accepted, and that error surfaces unchanged.
