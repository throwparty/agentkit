# T-003: bubblewrap as an unprivileged Linux sandbox

**Question.** Can bwrap confine a process on Linux without root, a daemon or a container runtime?

**Method.** Upstream README and man page.

**Observation.** `containers/bubblewrap` README:

> User namespaces ... allows unprivileged users to use container features. Bubblewrap uses these to build the sandbox, allowing any user to use the tool.

The man page describes user, mount, pid, ipc, uts and cgroup namespaces, bind mounts, `--unshare-net`, `--die-with-parent`, `--new-session` and `--disable-userns`.

The README also states that the level of protection "is entirely determined by the arguments passed to bubblewrap".

**Conclusion.** bwrap builds the sandbox from unprivileged user namespaces, with no root and no daemon. The arguments are the entire security policy, so owning the builder means owning the sandbox.
