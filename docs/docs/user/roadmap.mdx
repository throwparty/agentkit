# 💭 Roadmap

Below are some future ideas I'd like to flesh out. As components come into existence, their roadmap items will move to their sections.

## Bridgehead

The UI for managing agents.

## Sling

A TUI agentic coding client, which connects to a harness as an ACP client.

## Stethoscope

Language Server Protocol insight.

## Oracle

An MCP server providing code intelligence via existing Language Server Protocol implementations.

## Gavel

Code review for agents. A UI for you, and an MCP server for the agent to retrieve the comments and respond.

## Ledger

An MCP server providing basic todo list management for tasks. Maybe some ointegration with external ticketing systems.

## Probe

Exposes OpenTelemetry ingest to your applications and tools for agents to read them back.
