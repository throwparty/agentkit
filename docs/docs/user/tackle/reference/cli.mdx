# 👩‍💻 Command line interface

Tackle is a server launched by ACP clients — all session interaction, including resume, is client-driven over ACP. The CLI only selects the transport and overrides paths.

{/* Generated with `tackle docgen cli`; keep the sections below in sync with the output. */}

## `auth`

Manage stored credentials — store, inspect, and remove the bearer tokens Tackle resolves through the credential helper. Every credential lives under the helper's `tackle` component, keyed by identity: an endpoint name, or an MCP `{cred:IDENTITY}` marker.

### `add`

Store a bearer token for an identity.

Arguments:

- `identity` Endpoint name or MCP credential identity
- `value` The bearer token

### `status`

Report each configured endpoint and MCP credential identity with whether its credential resolves.

Arguments:

- `[identity]` Restrict the report to one identity (optional — omitting shows all)

### `token`

Print the resolved credential for an identity.

Arguments:

- `identity` Identity to resolve

### `logout`

Remove a stored credential.

Arguments:

- `identity` Identity to remove

Options:

- `--config-dir <CONFIG_DIR>` Override the user configuration directory (defaults to the platform config directory)
- `--credential-helper <CREDENTIAL_HELPER>` Override the credential helper name (defaults to the configured helper, or `keychain`)

## `definitions`

Manage definition sources, selections, and vendoring. `def` is an alias.

Options:

- `--project-dir <PROJECT_DIR>` Repository root (defaults to the current directory)

### `init`

Scaffold `.agentkit/tackle/definitions.toml`.

### `add`

Select a definition from a declared source.

Arguments:

- `source` Source name from the manifest
- `kind` `personas`, `actors`, or `prompts`
- `name` Definition name

### `remove`

Remove a selected definition.

Arguments:

- `source` Source name from the manifest
- `kind` `personas`, `actors`, or `prompts`
- `name` Definition name

### `get`

Vendor the locked revisions.

### `update`

Re-resolve refs, re-vendor, and rewrite the lock.

### `list`

Report declared and vendored definitions with status.

### `verify`

Check vendored packages against the lock.

## `http`

Serve the streamable HTTP transport

Multiple client connections in one process.

Options:

- `--bind <BIND>` Network interface to bind
- `--http-port <HTTP_PORT>` Port to listen on
- `--db-path <DB_PATH>` Override the session database location (defaults to the platform data directory)
- `--config-dir <CONFIG_DIR>` Override the user configuration directory (defaults to the platform config directory)

## `stdio`

Serve ACP over JSON-RPC on stdin/stdout

One process per client connection.

Options:

- `--db-path <DB_PATH>` Override the session database location (defaults to the platform data directory)
- `--config-dir <CONFIG_DIR>` Override the user configuration directory (defaults to the platform config directory)

## Paths

- **Session database** — `<data>/tackle/sessions.db` in the platform data directory (`~/.local/share/agentkit/tackle` on Linux, `~/Library/Application Support/AgentKit/tackle` on macOS), created with its leading directories if missing. Override with `--db-path`.
- **User configuration** — `<config>/tackle/config.toml` in the platform config directory (`~/.config/agentkit/tackle` on Linux), overridable with `--config-dir`.
- **Project configuration** — `.agentkit/tackle/config.toml` in the session's working directory; not configurable via the CLI.

## Shutdown

The process shuts down on Ctrl-C, or SIGTERM on Unix.
