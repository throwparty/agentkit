# 👋 Welcome

AgentKit provides a set of composable tools for building your own agentic software engineering environment, or for plugging in to your preferred environment. Each tool implements the relevant standards to make it reasonably interoperable.

- [Lens](lens): provides `fetch` and `search` tools backed by various search engines.
- [Litterbox](litterbox): review _outputs_, not _actions_: give your AI agents litter trays to poop into.
- [Switchboard](switchboard): a model provider proxy which forwards requests to upstream providers based on quota and pricing information and model configurations.
- [Tackle](tackle): an agent harness exporting an ACP interface, and only MCP for access to the outside world.
